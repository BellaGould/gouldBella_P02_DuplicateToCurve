# gouldBella_P02_DuplicateToCurve
Final project for ANGM 3311.003 Spring 2026 semester.

GitHub link: https://github.com/BellaGould/gouldBella_P02_DuplicateToCurve

This tool allows users to duplicate a specified mesh along the line of a specified curve in Maya. Great for adding small details along
complicated paths (like accents on a belt) or roughly fleshing out scenery (like rocks by the side of a river). There are options
for setting mesh rotation, creating duplicates or instances, and choosing the number of copies OR the preferred spacing of the copies
(including random spacing). This tool would benefit 3D modelers by speeding up their workflow and lessening the frustration of positioning
many tiny objects.
